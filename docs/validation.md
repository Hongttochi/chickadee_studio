## 동적 탐색과 요청 제한

직접 작성한 loopback 테스트 서버에서 다음을 확인했습니다. 실제 의심 사이트·광고 사이트에는 접속하지 않았습니다.

| 시나리오 | 결과 |
| --- | --- |
| 지연 GET 댓글 + 설정한 더보기 | 투명 문구와 전각 문구 검출, 동작·근거 기록 |
| JavaScript 페이지 이동 | 변경 전후 URL별 검출 보존 |
| HTTP 503 후 정상 응답 | 1회 재시도 후 완료 |
| 허용하지 않은 iframe origin | 다른 테스트 서버에 요청 미도달, 일부 결과 표시 |
| POST·WebSocket | 테스트 서버에 요청 미도달 |
| 폼 제출 컨트롤 | 클릭 거부, 서버 변경 없음 |
| 무관한 전각·자모, 정상 단어·예방 안내 | 해당 회귀 사례에서 오탐 없음 |
| 결과 파일 변조 | 보고서 SHA-256 불일치로 가져오기 거부 |
| 0건·중첩 기법·iframe·중단·한도·실패 | 표준 출력 및 상태 구분 |

요청 제한 검증은 테스트한 앱 경로에 대한 확인입니다. OS/VM 격리나 브라우저 취약점의 부재를 증명하는 보안 감사가 아닙니다.

## 아직 검증하지 않은 항목

별도 VM의 실제 공공사이트 실행, 실제 불법광고 정답셋의 정밀도·재현율, 모든 사이트의 페이지 이동·댓글 구조, 개발 도구가 없는 별도 PC에서의 배포본 실행은 남아 있습니다. 정책브리핑을 공개 검증 후보로 문서에 넣었지만 이 PC에서 브라우저 검사를 실행하지 않았습니다. 실제 정확도나 공모전 비공개 평가셋 통과를 주장하지 않습니다.
