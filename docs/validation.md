- `python scripts/validate_research.py`: 43개 레코드의 집계·중복·관찰 수준과 원본 8개 파일의 SHA-256 확인. 직접 관찰 38, 문헌 보고 5, 광고 의심 20, 정상 23입니다.
- 정상 원문 evidence_text 23건의 텍스트 단계 광고 판정 음성 확인. 이는 원본 사이트·전체 DOM의 정밀도 평가가 아닙니다.
- 새로 작성한 합성 문구·HTML로 혼합 한글/라틴 r, 부분 자모·공백, 광고 문맥의 COM 위장, 근사 투명도 0.003, 작은 상자·클리핑, 이스케이프된 HTML, 편집 버퍼 제외, 스크롤 전후 요소·iframe 판정을 확인했습니다.
- loopback 서버에서 HTTP 429 무재시도·후속 큐 중단·비동기 429 이후 새 요청 차단과 결과 보고서 저장·재불러오기를 확인했습니다. 503 재시도와 기존 동적 탐색·화면·출력 검사도 통과했습니다.
- Windows 폴더형 실행 파일 빌드 성공. 이번 빌드의 실행 확인 명령은 자동 승인 정책에서 `blocked by policy`로 차단되어 **0.3.0 실행 파일의 실제 구동은 미검증**입니다. 아래 0.2.0의 실행 파일 결과를 새 버전 검증으로 간주하지 않습니다.

원본 의심 사이트·광고 목적지에 접속하거나 수집된 HTML·스크립트를 실행하지 않았습니다. 원본의 정적 HTML 확인을 계산 CSS 검증으로 바꾸지 않았고, 합성 fixture는 원본 실사이트와 구분합니다. [반영 내역·남은 한계](research-integration.md)를 확인하세요. 실제 정밀도·재현율은 아직 측정하지 않았습니다.

## 동적 탐색과 요청 제한

직접 작성한 loopback 테스트 서버에서 다음을 확인했습니다. 실제 의심 사이트·광고 사이트에는 접속하지 않았습니다.

| 시나리오 | 결과 |
| --- | --- |
| 지연 GET 댓글 + 설정한 더보기 | 투명 문구와 전각 문구 검출, 동작·근거 기록 |
| JavaScript 페이지 이동 | 변경 전후 URL별 검출 보존 |
| HTTP 503 후 정상 응답 | 1회 재시도 후 완료 |
| 허용하지 않은 iframe origin | 다른 테스트 서버에 요청 미도달, 일부 결과 표시 |
| POST·WebSocket | 테스트 서버에 요청 미도달 |
| 폼 제출 컨트롤 | 클릭 거부, 서버 변경 없음 |
| 무관한 전각·자모, 정상 단어·예방 안내 | 해당 회귀 사례에서 오탐 없음 |
| 결과 파일 변조 | 보고서 SHA-256 불일치로 가져오기 거부 |
| 0건·중첩 기법·iframe·중단·한도·실패 | 표준 출력 및 상태 구분 |

요청 제한 검증은 테스트한 앱 경로에 대한 확인입니다. OS/VM 격리나 브라우저 취약점의 부재를 증명하는 보안 감사가 아닙니다.

## 아직 검증하지 않은 항목

별도 VM의 실제 공공사이트 실행, 실제 불법광고 정답셋의 정밀도·재현율, 모든 사이트의 페이지 이동·댓글 구조, 개발 도구가 없는 별도 PC에서의 배포본 실행은 남아 있습니다. 정책브리핑을 공개 검증 후보로 문서에 넣었지만 이 PC에서 브라우저 검사를 실행하지 않았습니다. 실제 정확도나 공모전 비공개 평가셋 통과를 주장하지 않습니다.
