# Windows 배포

Windows x64용 미서명 ZIP을 제공합니다. 전체 압축을 풀고 `Chickadee.exe`를 실행하며 동봉된 `resources` 폴더를 함께 유지합니다.

빌드 과정의 `windows-signatures.json`에는 파일의 서명 상태를 기록합니다. 배포본은 인증서 설치나 PC 보안 설정 변경을 수행하지 않습니다.

[빠른 실행](quickstart-windows.md) · [최신 릴리스](https://github.com/orqan137/chickadee_studio/releases/latest)
