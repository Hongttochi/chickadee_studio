[행정안전부 공식 공고](https://www.mois.go.kr/frt/bbs/type013/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000006&nttId=129458) 또는 [NIA 공식 공고](https://www.nia.or.kr/site/nia_kor/ex/bbs/View.do?bcIdx=29988&cbIdx=99835&parentSeq=29988)의 첨부 HWPX에 편집 가능한 서식 1~4가 있습니다.

## 접수

- [ ] 2026년 10월 23일(금) **18:00 이전** 접수
- [ ] 접수 이메일: `gongmo@aipubcon.kr`
- [ ] 이메일 제목: `공모_작품명_팀명 또는 성명`
- [ ] 개인 또는 최대 5명 팀의 참가자격 확인
- [ ] 최신 공지의 일정·제출 방식 변경 여부 확인

## 신청 서류

- [ ] 서식1 참가신청서 1부: 작품명, 요약, 활용 데이터·주요 기술, 대표자·팀원 정보
- [ ] 서식2 참가 서약서 1부: 대표자 작성 및 서명
- [ ] 서식3 개인정보 수집·이용 동의서: **팀 전원** 작성 및 서명
- [ ] 서식4 기획서 1부: **5~10매**, 이미지 파일은 문서 안에 포함
- [ ] 미작성 항목, 서명 누락, 서식 규격 위반 확인

기획서는 개발 배경·목적, 상세 기능·활용 데이터·기술·구현 과정·구조와 사용자 흐름, 결과 안내·관리 화면, 활용방안·기대효과를 다룹니다. 근거가 필요한 동향·통계와 예상 효과는 출처·측정 근거를 확보한 후 작성합니다. 이 저장소의 개발 계획은 최종 기획서를 대신하지 않습니다.

## 개발 산출물

- [ ] Windows 11에서 실행 가능한 구동 파일
- [ ] 전체 소스코드와 의존성·버전 정보
- [ ] 실행·빌드 매뉴얼: 깨끗한 환경에서 재현 가능한 절차
- [ ] 사용설명서: URL 입력, 탐지 시작, 결과 확인, 오류·제한 안내
- [ ] `result.json` 생성 확인: 실행 파일 폴더가 기본
- [ ] 추가 탐지 기능을 구현한 경우 `result_extra.json` 생성 확인
- [ ] 다른 폴더에 저장한다면 사용설명서 **첫 장에 파일별 생성 경로** 명시
- [ ] 예시 JSON이 아닌 프로그램의 실제 출력 파일로 검증

## AI API 또는 외부 연산을 사용하는 경우

기본 OCR·로컬 ML은 외부 API 없이 동작합니다. 선택 AI 검토는 Groq의 `openai/gpt-oss-20b`를 기본 모델로 사용합니다. 이 기능을 제출본에 포함할 경우 아래 설정·문서 요건을 확인합니다.

- [ ] API 키 하드코딩 금지, `.env` 등 외부 설정 파일에서 실행 시 읽기
- [ ] 주최 측 키로 교체해도 재빌드·재컴파일 없이 정상 동작
- [ ] 사용설명서에 서비스명·모델명·환경변수 이름 명시
- [ ] 실제 키를 제외한 설정 예시와 필요한 환경 설명 제공
- [ ] 자체 외부 서버의 구축·가용성·비용은 참가자 부담임을 확인
- [ ] 심사 기간 10월 26일~11월 4일(변동 가능) 외부 서버 접속 유지
- [ ] 상용 API 개발·테스트 비용과 심사 시 주최 측 키 사용 조건 확인
