# 구현 구조와 실행 경계

![GPT로 생성한 아키텍처](assets/architecture-gpt.png)

외부 사이트 검사와 사용자 PC의 결과 조회를 분리해 사용할 수 있는 0.2.0 구조입니다. 그림의 VM은 사용자가 별도로 구성하는 실행 환경입니다. 프로그램에 VM 생성·자동 격리·원격 VM 접속 기능이 들어 있다는 뜻이 아닙니다.

| 구성 | 구현 | 역할 |
| --- | --- | --- |
| 화면 / CLI | `chickadee/gui.py`, `__main__.py` | 입력, 중단, 결과 불러오기, 유형·원문·근거 조회 |
| 탐색 제어 | `scanner.py` | URL 큐, 재시도, 시간·페이지 한도, 지연 로딩·스크롤·읽기 동작 |
| 요청 정책 | `scanner.py` | loopback 기본값, origin 허용 목록, GET/HEAD, 자원·WebSocket 차단 |
| DOM 수집 | `extract.js`, `_inspect_frame` | 원문, 선택자, CSS·좌표, 중첩 iframe 경로 |
| 규칙 분석 | `detection.py`, `rules.json` | 키워드의 원문 문자 추적, 필수 기법 4종, 예방 안내 제외 |
| 사이트 설정 | `profiles.py`, `profiles/` | 경로 범위·읽기 선택자·리소스 origin, 실행 코드 없는 JSON |
| 결과 처리 | `ScanOutcome` | 표준 결과 검증, 중복 검사, 원자적 교체, 보고서 해시·불러오기 |

사용자 PC 기본 실행에서는 실제 외부 URL을 거부합니다. 실제 사이트 검사는 별도 VM에서 `--network`로 실행한 후 결과 JSON 두 파일만 옮깁니다. 결과 조회는 원본 URL을 열거나 HTML을 렌더링하지 않습니다. GUI를 `--network`로 시작하면 해당 실행에서도 외부 검사를 허용하므로 검사 VM 안에서만 사용해야 합니다.

브라우저 내장 sandbox를 켜고 임시 컨텍스트를 사용하지만, 이 정책이 브라우저 취약점이나 모든 통신·부수 효과를 통제하는 OS 보안 경계는 아닙니다. 계정·개인 데이터·호스트 공유 자원을 검사 환경에 연결하지 않는 운영 구성이 별도로 필요합니다.

외부 AI API, 학습된 불법성 분류 모델, 원격 서버나 DB는 사용하지 않습니다. 규칙 기반 의심 항목이며 실제 사이트 정확도와 비공개 평가셋 성능은 별도 검증 대상입니다. 이 PC에서는 실제 의심 광고 페이지를 실행하지 않았습니다.

주 이미지에는 GPT 이미지 생성 도구를 사용했습니다. [생성 프롬프트](assets/architecture-prompt.txt)와 [편집 가능한 구조 원본](assets/architecture.drawio)을 함께 보관합니다. 그림보다 코드·이 문서의 동작 조건을 기준으로 판단합니다.
