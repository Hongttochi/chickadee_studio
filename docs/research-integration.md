`dom_verified` 28건은 **정적 HTML의 문자·태그·선언 확인**을 뜻합니다. `visible_only` 10건도 화면 캡처가 아닌 텍스트 판독 수준입니다. 모든 원본 레코드의 `computed_style`, `bounding_box`, `viewport`는 null입니다. 직접 조사 광고 중 목표 기법이 기록된 것은 7건이며, HOMOGLYPH 4·JAMO 1·OFFSCREEN 3의 중첩을 포함합니다. 직접 확인된 TRANSPARENT 사례는 0건입니다.

원본 파일 바이트와 SHA-256을 `import-manifest.json`에 기록했습니다. Git 줄바꿈 변환도 이 폴더에는 적용하지 않습니다. 아래 검사는 네트워크 없이 해시·필수 메타데이터·중복·관찰 경계·집계를 재검증하며, 조사자의 해석이나 실제 사이트의 현재 상태를 검증하지는 않습니다.

## 남은 한계

권유 신호를 요구하므로 광고 키워드만 들어 있는 짧은 숨김 링크를 놓칠 수 있습니다. 근접 문맥은 문장 경계와 키워드 전후 최대 160자로 제한합니다. 정상 제외어가 섞인 광고, 인용을 가장한 광고, 다른 요소의 제목·본문을 의미적으로 연결해야 하는 사례도 누락될 수 있습니다. A010·A011의 접미부 발췌만으로 원본 제목과 본문의 연관을 자동 검증했다고 주장하지 않습니다.

문구·언어·CSS 규칙은 제한적이며 이미지 OCR·Shadow DOM·모든 CSS 가림을 지원하지 않습니다. 429를 받기 전에 이미 출발한 요청은 되돌릴 수 없습니다. 이 자료로 실제 사이트 정밀도·재현율·법적 불법성이나 VM의 안전성을 증명하지 않습니다. 실제 사이트 검증은 개인 PC가 아닌 별도 VM에서 진행해야 합니다.
