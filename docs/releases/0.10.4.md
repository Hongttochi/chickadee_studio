# 0.10.4

- 사용 가이드를 검사 시작, 구성·OCR, 속도·환경, 진행 확인, 탐지·검토, AI 검토, 기록·내보내기, 예약 검사, 알림, 앱 관리의 10개 주제로 다시 작성했습니다.
- 현재 앱의 화면 예시 10장을 반영하고, OCR 생략 조건·예약 실행 조건·AI 키와 사용 한도·결과 보관 및 ZIP 업데이트 방법을 상세히 설명합니다.
- 주제 바로 선택, 화면 확대, 본문 스크롤을 지원하며 작은 창에서도 이전·다음 버튼을 사용할 수 있도록 가이드 레이아웃을 정리했습니다. 중복된 다시 열기 안내를 제거했습니다.
- 광고 분류 아이콘의 투명 여백을 고려해 노드와 설정 패널의 아이콘을 키웠습니다. 재실행 버튼의 툴팁은 ‘앱 재실행’만 표시합니다.
- README와 데스크톱 사용설명서를 최신 가이드에 맞췄습니다. 기존 직접 이미지·텍스트 분석 백엔드와 OCR·로컬 AI 기능은 유지합니다.

이번 배포는 **미서명 Windows x64 ZIP**입니다. Windows에서 게시자를 확인할 수 없다는 경고가 나타나거나 실행이 제한될 수 있습니다. 인증서를 설치하거나 운영체제 보안 설정을 변경하지 않습니다. macOS 배포 파일은 포함하지 않습니다.
