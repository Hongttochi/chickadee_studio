# 0.10.2

- 검사 구성을 고정된 파이프라인으로 정리했습니다. 연결선 편집·삭제를 제거하고, 기존 구성도 고정 경로로 복원합니다. 이미지 OCR 사용 여부는 노드 설정에서 선택할 수 있습니다.
- 이미지에서 추출한 문구에도 본문과 같은 필수 탐지·광고 분류를 적용합니다. 같은 페이지·유형·문구의 본문과 OCR 결과는 합치고 원문, 위치, 이미지 근거를 보존합니다.
- OCR 처리 실패·판독 불가·생략을 별도로 기록하고 미확인 항목을 결과 화면에 안내합니다. 실행 환경의 절약 모드와 이미지 처리 한도를 유지합니다.
- 검사 진행 중에도 수집된 근거 스크린샷을 표시합니다. 확대는 중앙 모달에서 열리며, 촬영 정보의 URL은 기본 브라우저로 바로 열 수 있습니다.
- 분석 중 로딩 스피너, 앱 재실행 버튼, 하단 도구 설명을 추가했습니다. 오류 안내, 노드 배치, OCR·중복 정리 아이콘, Groq 연결 화면의 로고와 여백을 다듬었습니다.

로컬 문자·화면 AI와 실행 환경 설정은 유지됩니다. AI 추가 검토는 사용자가 등록한 Groq API 키로만 요청합니다.

Windows 정식 릴리스는 기존 정책에 따라 공인 코드 서명 검증과 패키지 실행 검사를 통과한 경우 게시됩니다.
