# 0.10.18

[한국어](0.10.18.md) | [English](0.10.18.en.md)

- Updated Electron to **46.0.0-alpha.1** and Playwright to **1.64.1** for Node2Shell (CVE-2026-111497). Both bundled Node.js runtimes are **24.22.1**. This distribution uses an alpha release of Electron.
- Migrated encrypted notification settings to Electron 46's asynchronous secure storage API, including its decryption result object.
- Simplified evidence cards with white backgrounds, thin separators and restrained corners. Removed nested colored boxes and the thick quotation border; moved screenshot enlargement beside its caption.
- Replaced the colored images for Save note and Mark unreviewed with the same line icons used by other menus.
- Updated the user guide and screenshots, and refined view transitions, app icons and HTTP activity labels.
- Windows builds reuse the installed official Electron distribution without its demo app, retaining executable and ASAR integrity verification. Separate Python environments and output directories are supported.
- Updated app updates and model downloads to the transferred official repository, `Kafrika-Labs/chickadee_studio`. Existing model configuration and weight checksums are retained.

Extract the entire ZIP into a new folder and run `Chickadee.exe`. Keep the executable and its `resources` directory together.
