# 0.10.3

- 이미지·텍스트 직접 분석 백엔드 `content.analyze`를 추가했습니다. 무료 로컬 OCR·문자/이미지 모델을 호출하고 입력 텍스트와 OCR 문구를 출처별로 반환합니다. 새 화면이나 버튼, Groq 자동 호출은 추가하지 않았습니다.
- 사이트 검사와 직접 분석이 같은 OCR 신뢰도 기준을 사용하며, 잘린 문구 여부·채택한 줄 수·평균 신뢰도를 보존합니다.
- Groq 에이전트가 같은 사이트를 추가 탐색한 이미지도 원본·OCR 좌표·문구·해시를 저장합니다. 이미지 ID 충돌을 방지하고, 다시 열 때 파일 무결성을 검증합니다. 추가 페이지 수집은 전체 30초 안에서 OCR 초기화 시간을 고려해 최대 20초를 배정합니다. 호출·토큰·방문 한도는 유지합니다.
- 최신 0.10.2의 고정 검사 흐름·근거 확대·화면 디자인을 유지했습니다.
- 서명 서비스 신청·승인 대기 및 서명 필수 배포 조건을 제거했습니다. 자동 테스트를 통과한 미서명 Windows ZIP을 배포하며 PC 보안 설정은 변경하지 않습니다. Windows 자체 정책에 의한 실행 차단이 해결되었다는 의미는 아닙니다.
