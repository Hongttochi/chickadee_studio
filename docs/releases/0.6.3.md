# Chickadee Studio 0.6.3

Windows x64 프리릴리스입니다. `Chickadee-Studio-0.6.3-win-x64.zip`을 전체 압축 해제한 뒤 `Chickadee-0.6.3/Chickadee.exe`를 실행하세요. Python·Node.js를 따로 설치하지 않아도 됩니다.

## 검사 화면

- 검사 구성을 어두운 노드 캔버스로 정리하고, 각 단계에 전용 이미지 아이콘을 적용했습니다.
- 검사 대상 노드를 누르면 URL을 입력할 수 있습니다. 검사 실행·정지·결과 폴더는 상단에서 조작합니다.
- 미리보기와 진행 기록 패널을 접고 펼칠 수 있습니다. 패널 너비에 맞춰 캔버스 배치가 조정됩니다.
- 노드 위치를 기억하며, 새로고침 때 저장 구성을 불러온 뒤 캔버스를 생성해 연결선 초기화가 겹치지 않도록 수정했습니다.

## 결과 확인과 검토

- 탐지 유형·검토 상태·검사 상태를 서로 다른 배지로 구분했습니다.
- 탐지 항목을 선택하면 원문과 근거가 오른쪽에 표시됩니다. 검토 메모·최근 검토 정보·페이지 및 기술 정보는 펼쳐서 볼 수 있습니다.
- 검토 저장 완료는 중앙 모달로, 복사 완료는 알림으로 안내합니다.
- 필터를 앱 드롭다운으로 통일하고 탭 밑줄·접이식 항목·패널에 전환 애니메이션을 추가했습니다. 동작 줄이기 설정을 따릅니다.
- 탐지 내역·탐색 경로·검사 기록·대기 화면에 전용 빈 화면 이미지를 적용했습니다.

## 사용 가이드와 macOS 개발 실행

- 실제 화면 예시, 확대 보기, 검사 시작·검토·저장 절차를 담은 사용 가이드를 추가했습니다.
- macOS 소스 실행 시 Python 아키텍처를 맞추고, `npm start`에서 Chickadee 이름과 Dock 로고를 사용하는 개발 번들을 준비합니다.
- **이번 다운로드 배포는 Windows x64만 제공합니다. macOS 변경은 개발용 소스 실행에 해당합니다.**

## 사용 시 참고

- 동봉된 실행 파일과 `resources` 폴더를 함께 유지하세요.
- Windows 코드 서명은 포함하지 않았습니다. 기존과 같은 프리릴리스 배포입니다.
- 탐지 결과는 검토 대상입니다. 원문과 탐지 근거를 함께 확인하세요.
- ZIP과 함께 제공되는 SHA256 파일로 다운로드 무결성을 확인할 수 있습니다.
