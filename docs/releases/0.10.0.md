# Chickadee 0.10.0

게시글 이미지의 한국어 문구를 읽고 탐지 근거에서 이미지와 글자 위치를 함께 확인할 수 있습니다.

## 주요 변경

- **이미지 OCR**: 공식 PaddleOCR PP-OCRv5 모바일 탐지 모델과 한국어 인식 모델을 CPU에서 실행합니다. PNG·JPEG·WebP·GIF와 CSS 배경 이미지를 수집합니다.
- **이미지 탐지 근거**: 인식 문구, 줄별 신뢰도, 위치 상자를 표시합니다. 문구를 선택하면 이미지의 해당 영역이 강조됩니다.
- **기록과 원본 보관**: `scan-report.json`에 OCR 결과를 저장하고 `evidence/images/`에 원본 이미지를 SHA-256 이름으로 보관합니다. 검사 기록을 다시 열어도 이미지 근거가 표시됩니다.
- **기존 탐지와 연계**: OCR 문구에 기존 광고 문맥 규칙을 적용해 광고 의심 항목을 생성하고, AI 검토용 수집 근거에도 포함합니다. 필수 4종 `result.json`과 CSV 칼럼은 유지합니다.
- **로컬 실행**: OCR 모델을 배포본에 동봉하며 실행 중 모델 다운로드나 유료 OCR API를 사용하지 않습니다. 기존 AI 설정과 호출·토큰 한도를 유지합니다.
- **업데이트 주소**: 변경된 `chickadee_studio` 저장소에서 업데이트를 확인합니다.
- README와 사용 안내 문구를 정리했습니다.

## 설치

`Chickadee-Studio-0.10.0-win-x64.zip` 전체를 압축 해제하고 `Chickadee-0.10.0/Chickadee.exe`를 실행하세요. Python·Chromium·OCR 모델이 포함됩니다.

## 검증

실제 한국어 이미지 인식, 정상 안내문 제외, iframe·배경·내장 이미지 수집, 외부 이미지·리다이렉트 요청 차단, 원본 저장과 재열기를 회귀 검사합니다. Windows 배포본도 실제 OCR과 근거 화면을 검사한 후 게시합니다.
