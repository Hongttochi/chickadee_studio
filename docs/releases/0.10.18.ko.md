# 0.10.18

[한국어](0.10.18.ko.md) | [English](0.10.18.md)

- Node2Shell(CVE-2026-111497) 대응을 위해 Electron을 **46.0.0-alpha.1**, Playwright를 **1.64.1**로 업데이트했습니다. 두 내장 Node.js 런타임은 **24.22.1**입니다. 이 배포는 Electron 알파 버전을 사용합니다.
- Electron 46의 비동기 보안 저장소 API에 맞춰 알림 설정의 암호화·복호화를 갱신했습니다.
- 탐지 근거는 흰 배경, 얇은 구분선, 절제된 모서리로 정리했습니다. 원문 왼쪽 강조선과 중첩된 색상 박스를 제거하고 스크린샷 확대를 제목 옆으로 옮겼습니다.
- 검토 작업의 ‘메모 저장’·‘미검토로 변경’을 다른 메뉴와 같은 선형 아이콘으로 통일했습니다.
- 사용 가이드와 안내 이미지를 갱신하고 화면 전환, 앱 아이콘, HTTP 활동 표시를 다듬었습니다.
- Windows 빌드에서 설치된 공식 Electron 런타임을 재사용하고 기본 데모 파일을 제외합니다. 기존 실행 파일·ASAR 무결성 검증을 유지하면서 별도 Python 환경과 출력 폴더를 지원합니다.
- 앱 업데이트와 모델 다운로드 주소를 이전된 공식 저장소 `Kafrika-Labs/chickadee_studio`로 수정했습니다. 기존 모델 설정·가중치 체크섬은 유지합니다.

ZIP 전체를 새 폴더에 압축 해제한 뒤 `Chickadee.exe`를 실행하세요. 실행 파일과 `resources` 폴더를 함께 유지해야 합니다.
