# Chickadee Studio 0.6.2

Windows x64 프리릴리스입니다. `Chickadee-Studio-0.6.2-win-x64.zip`을 전체 압축 해제하고 `Chickadee-0.6.2/Chickadee.exe`를 실행하세요. Python·Node.js·Docker 설치는 필요하지 않습니다.

## 변경 사항

- GitHub Actions에서 Windows 앱, Python 검사 엔진과 Chromium을 함께 빌드하도록 배포 절차를 자동화했습니다.
- 버전·릴리스 노트 일치 여부, ZIP 필수 파일·CRC와 SHA256을 검사한 뒤 게시합니다.
- Python 회귀 검사, 데스크톱 단위 검사와 패키징된 Windows 앱의 데모 통합 검사를 게시 전 단계로 연결했습니다.
- 저장소에 공용 `github-release-manager` 스킬을 포함했습니다.

앱 기능은 0.6.1과 동일합니다. 이 버전은 배포 자동화를 위한 업데이트입니다.

## 사용 시 참고

- `Chickadee.exe`와 `resources` 등 동봉 파일을 같은 폴더에 유지하세요.
- 인증서 서명은 포함하지 않았습니다. 조직의 Windows 보안 정책에 따라 실행이 제한될 수 있습니다.
- 자동 검사는 로컬 데모와 테스트용 페이지를 대상으로 합니다. 실제 사이트의 탐지 정확도나 모든 Windows PC에서의 실행을 보장하지 않습니다.
- SHA256 파일은 ZIP과 같은 폴더에 놓고 다운로드 무결성을 확인할 때 사용합니다.
