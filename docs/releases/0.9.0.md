# Chickadee 0.9.0

검사 설정과 AI 검토 화면을 정리하고, 예약 검사·알림·업데이트 확인을 추가했습니다.

## 주요 변경

- **설정 페이지**: 검색 가능한 측면 메뉴, 단축키 지정, 사용 가이드, AI 연결 설정을 제공합니다.
- **예약 검사**: 한 번·매일·요일별로 검사 구성을 저장해 실행합니다. 앱이 켜져 있고 컴퓨터가 깨어 있을 때 작동합니다. 놓친 일정과 실행 중 겹친 일정은 건너뜁니다.
- **탐색 속도**: 빠르게·보통·천천히와 0~30초 페이지 간 대기 시간을 지원합니다. 예약에도 저장되며, 긴 검사는 전체 제한시간을 함께 늘려야 합니다.
- **알림**: 검사 완료 시 시스템 알림과 Slack·Discord 웹훅 리포트를 지원합니다. 웹훅은 OS 암호화 저장소를 통해 보관합니다.
- **AI 검토**: xAI Grok 연결로 전환하고 전체 수집 영역을 순서대로 검토합니다. 요청·토큰 사용량과 미검토 영역을 표시하고 완료된 의견을 Markdown으로 저장할 수 있습니다. API 키는 세션 메모리에 보관합니다.
- **변경 비교 제거**: 오탐이 많던 변경 비교 화면과 자동 비교 생성을 제거했습니다.
- **업데이트**: GitHub 릴리스 확인, 현재 OS용 ZIP 다운로드, SHA256 검증을 지원합니다. 자동 앱 교체는 지원하지 않습니다.
- **화면 개선**: 탐색 그래프 START 초점, 스크린샷 표시, 안내 툴팁, 아이콘 크기, 상단·측면 정렬과 전환 애니메이션을 정리했습니다.

## 설치

Windows x64에서는 `Chickadee-Studio-0.9.0-win-x64.zip`을 내려받아 전체 압축을 풀고 `Chickadee-0.9.0/Chickadee.exe`를 실행하세요. Python 엔진과 Chromium이 포함됩니다. SHA256 파일도 함께 제공합니다.

이번 릴리스의 배포 파일은 **Windows x64**입니다. macOS 배포 파일은 포함되지 않습니다. 기존 앱을 실행 중이면 완전히 종료한 뒤 새 앱을 실행하세요.


## 검증

Release 워크플로에서 Python 회귀 테스트, 데스크톱 단위 테스트, 패키징된 Windows 앱 검사, ZIP 필수 파일 검사와 SHA256 검증을 통과한 경우 게시합니다.
