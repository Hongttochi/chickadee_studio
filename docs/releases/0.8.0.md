# Chickadee Studio 0.8.0

Windows x64 프리릴리스입니다. ZIP 전체를 압축 해제한 뒤 `Chickadee-0.8.0/Chickadee.exe`를 실행하세요. 엔진과 Chromium이 포함됩니다.

- **근거 부족 항목 추가 탐색**: Groq 분석에서 근거 부족·보류가 나오면 관측된 같은 사이트 링크 중 최대 2개를 선택해 Chromium으로 추가 확인한 뒤 재판정합니다. 페이지 원문과 앱이 허용한 링크 ID만 사용하며 임의 주소·명령·폼 제출은 허용하지 않습니다.
- **과정과 기록**: 추가 탐색 페이지·원문·차단 요청·화면과 Groq 의견을 `agent.json`에 저장합니다. 탐색 그래프에서도 추가 확인 경로를 표시합니다. 원본 `result.json`·CSV·검사 보고서는 변경하지 않습니다.
- **비용 한도 유지**: 제공자는 Groq 하나입니다. 기본 검사별 누적 6회/24,000토큰과 요청 전 예약을 유지하며, 추가 탐색이 필요한 분석은 최대 4회 모델 호출입니다. 총 30초·추가 페이지 최대 2개/분석 및 6개/검사입니다. 예산 부족·실패·취소 때 자동 재시도하지 않습니다.
- **탐지 근거 화면**: 필수 탐지와 광고 후보가 나온 당시의 실제 viewport를 촬영합니다. 근거 패널에서 이미지·확대·촬영 시각·SHA-256을 확인하고, 저장 기록에서도 다시 볼 수 있습니다. 원본 JPEG는 결과 폴더의 `evidence/`에도 저장합니다. 투명·화면 밖 요소를 강제로 드러내거나 이미지를 Groq에 보내지 않습니다.
- **리다이렉션 제한 보강**: HTTP 이동을 브라우저에 자동으로 넘기지 않고 각 목적지를 검사합니다. 허용한 같은 origin의 상위 페이지 이동은 새 탐색으로 따라가며, 사이트 밖 HTTP·JS·meta 이동은 검사 브라우저에서 차단합니다. 리소스·iframe의 HTTP 리다이렉션은 보수적으로 차단해 일부 콘텐츠가 누락될 수 있습니다.
- **디자인 유지**: 기존 테마·타이포·배치를 유지하고 근거 이미지와 조사 과정만 독립 컴포넌트에 추가했습니다.

로컬 Python 77개, JavaScript 3개 검사와 실제 Python bridge를 연결한 화면 시험을 통과했습니다. 실제 Groq + 로컬 합성 게시판에서 4회 호출/2,887토큰으로 추가 탐색·재판정·화면 촬영을 확인했습니다. 실제 피싱 판별 정확도나 모든 프롬프트 주입에 대한 방어 성능을 입증한 시험은 아닙니다.

이 앱은 광고 위장·은닉과 광고 문맥을 조사합니다. Groq 의견은 피싱 확정 판정이 아니며, PC 전체나 일반 브라우저의 접속을 차단하는 제품도 아닙니다. 사용 방법과 범위는 [검사 분석 안내](../inspection-agent.md)를 참고하세요.
