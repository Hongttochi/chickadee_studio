# Chickadee Studio 0.7.0

Windows x64 프리릴리스입니다. `Chickadee-Studio-0.7.0-win-x64.zip` 전체를 압축 해제하고 `Chickadee-0.7.0/Chickadee.exe`를 실행하세요. 앱·검사 엔진·Chromium이 포함됩니다.

## 검사 분석

- 실제 방문 페이지, DOM 상태, 스크롤·읽기 동작, iframe 수집을 탐색 그래프로 표시합니다.
- 같은 시작 URL의 직전 검사와 원문·링크·스타일 변경을 자동 비교합니다. 이전 기준을 직접 선택하고 저장된 비교를 다시 열 수 있습니다.
- 미관측은 삭제 확정과 구분하며, 수집 범위와 한도를 표시합니다.
- Unicode 공식 데이터의 제한 매핑을 적용해 닮은꼴 문자 탐지를 확장하고, 원문 위치·혼합 문자·형식 문자 삽입 근거를 보존합니다.

## Groq 근거 조사

- 선택한 수집 영역에 대해 Groq가 근거 조회 도구를 선택하고 구조화된 검토 의견을 제공합니다. 기존 필수 결과와 사람 검토는 변경하지 않습니다.
- 외부 AI API는 Groq만 사용합니다. 자동 호출·다른 제공자 전환·유료 검색 API는 없습니다.
- 기본 모델은 Groq의 `openai/gpt-oss-20b`입니다. 키는 환경변수 `GROQ_API_KEY` 또는 앱의 세션 입력을 사용합니다.
- 검사별 누적 호출·토큰 한도, 요청 전 예약, 실패 사용량 보존, 취소·시간 제한을 적용합니다.
- 전송 문구·관측값과 마스킹의 한계는 [사용 안내](../inspection-agent.md)를 확인하세요.

## 새 디자인 통합과 확인 범위

- 0.6.3의 새 노드 캔버스·모니터링 화면·가이드를 보존했습니다. 새 분석 기능은 별도 컴포넌트로 분리했습니다.
- 로컬 Python 73개·JavaScript 3개 검사와 실제 Python bridge를 연결한 기존·신규 화면 통합 검사를 통과했습니다.
- 실제 Groq에서 합성 광고 1건의 도구 호출·JSON 판정을 확인했습니다. 추가 합성 주입 시험은 누적 호출 한도에서 중단되어 최종 판정을 완료하지 않았습니다. 실제 사이트 정확도나 포괄적인 에이전트 보안 검증을 의미하지 않습니다.
- Windows 패키지 실행·ZIP·SHA-256 검증은 이 릴리스를 게시하는 GitHub Actions에서 수행합니다. 사용자 PC별 보안 정책과 인증서 서명은 별도 사항입니다.
