# 0.10.1

- 학습한 문자 문맥 Random Forest와 피싱 화면 특징 Random Forest를 오프라인 AI 분석으로 연결했습니다. 모델은 실행 코드가 없는 JSON 트리로 포함하며 해시를 확인합니다.
- 기존 근거 패널에 문자 문맥·피싱 화면 분석을 표시하고 AI 검토 화면에서 로컬 분석 결과를 확인할 수 있습니다. 이미지 OCR 원문·좌표와 캡처, 검사 기록 복원을 유지합니다.
- 로컬 문자 모델에서 우선 검토로 분류한 문구를 AI 광고 문맥 후보로 저장합니다. 결과의 필수 탐지 4종과 AI 후보는 구분합니다.
- Groq만 사용하며 기본 모델을 현재 제공되는 `openai/gpt-oss-20b`로 변경했습니다. 이 모델의 요청도 Groq API에만 전달됩니다. 원문과 함께 로컬 분석을 전달하고 별도 도구로 조회할 수 있습니다. 호출·토큰 한도와 같은 사이트 추가 탐색 제한을 유지합니다.
- 한국어 OCR은 기존 공식 모델을 사용합니다. 합성 데이터로 점검한 OCR 체크포인트는 제품 기본값으로 교체하지 않습니다.
- 설정 → 일반의 ‘실행 환경’에서 CPU·메모리·사용 가능한 모델을 확인하고 자동·표준·절약 모드를 선택할 수 있습니다. 자동 모드는 검사 시작 시 자원을 확인하며, 절약 모드는 이미지 OCR을 생략합니다. 선택한 모드와 OCR 생략 내역은 검사 보고서에 저장됩니다.
- ‘OCR 기능 확인’은 자체 빈 이미지로 공식 한국어 모델을 실제 구동합니다. 파일 존재 여부와 구동 결과를 구분하고, 이 확인에는 사이트 접속이나 유료 API가 필요하지 않습니다.
- 앱의 문자·화면 AI 추론에서 학습용 NumPy·scikit-learn 의존성을 제거했습니다. 원본 모델과 200개 이미지·80개 문자 입력의 추론 결과가 일치하는지 확인했습니다.

로컬 AI는 별도 설치·API 키 없이 동작합니다. Groq 추가 검토는 사용자가 AI 연결 설정에 자신의 키를 입력한 뒤 실행합니다. 앱은 환경 변수·다른 프로젝트의 키를 자동으로 사용하지 않으며 입력한 키는 앱 종료 시 삭제됩니다. 키는 배포 파일에 포함하지 않습니다.

Windows 정식 릴리스는 공인 서명 확인과 네이티브 실행 테스트를 모두 통과해야 게시됩니다. 무료 SignPath 연결은 신청·심사·프로젝트 설정 이후 활성화할 수 있으며, 현재는 서명 자격증명 미등록 상태입니다.
