# 개발 계획

이 문서는 구현 제안입니다. 체크되지 않은 항목은 아직 개발·검증하지 않았습니다.

## 1차 목표: 필수 4종을 끝까지 실행

1. URL 입력과 탐지 시작 버튼, 진행률·오류·완료 상태를 제공한다.
2. 브라우저로 시작 페이지를 열고 내부 링크를 따라 게시글·댓글을 수집한다.
3. 각 페이지와 중첩 iframe에서 텍스트, 원문 DOM, 적용 CSS, 요소 위치를 추출한다.
4. 광고 의심 문구와 위장·은닉 기법을 결합해 결과를 만든다.
5. 결과 표에 원문·유형·URL·위치를 표시하고 `result.json`을 저장한다.
6. Windows 11 배포본을 깨끗한 PC에서 실행해 검증한다.

## 후보 기술 구성

| 역할 | 후보 | 선택 이유 |
| --- | --- | --- |
| 탐색·DOM·CSS 수집 | Python + Playwright Chromium | 동적 렌더링과 iframe, 계산된 스타일 확인 |
| 판정 | Python 규칙 엔진 | GPU·외부 API 없이 필수 기법부터 검증 |
| 데스크톱 화면 | PySide6 | 입력·진행 상태·결과 표 제공 |
| 배포 | PyInstaller 폴더형 패키지 | 실행 파일과 브라우저 리소스 동봉 검증 |

패키지 버전, 설치 방법, 브라우저 포함 방식은 프로토타입을 만든 뒤 확정합니다. 배포본 실행 시 Python·개발 도구·브라우저 추가 다운로드가 필요하지 않도록 검증하는 것이 목표입니다. AI API는 기본 구현에 필수로 넣지 않습니다.

## 탐색과 판정 원칙

- **범위:** 같은 사이트 내부 탐색을 기본으로 하고, 페이지에 삽입된 외부 iframe은 별도 수집 대상으로 다룹니다. 광고 외부 링크를 무제한 따라가지는 않습니다.
- **누락 방지:** 쿼리로 구분되는 게시글, 페이지 이동, 동적 댓글, 지연 로딩을 확인합니다. 접근 실패와 탐색 한도를 화면·로그에 표시합니다.
- **시간 관리:** 페이지별 제한시간, 전체 제한시간, 중복 방문 제거와 제한된 동시 처리를 둡니다. 제한에 도달해도 완료된 결과를 저장하고 미완료 상태를 안내합니다.
- **원문 보존:** 탐지용 정규화 문자열을 별도로 만들고 `evidence_text`에는 공백·문자를 임의 변경하지 않은 원문을 사용합니다. 숨김 텍스트가 빠질 수 있는 `innerText`만으로 수집하지 않습니다.
- **닮은꼴:** 전각 문자 정규화와 별도의 유사 문자 매핑을 함께 검토합니다. NFKC만으로 모든 키릴 위장을 복원할 수 있다고 가정하지 않습니다.
- **자모:** 호환·결합 자모 복원과 분리된 광고 키워드 검출을 검증합니다.
- **스타일:** 요소와 조상에 적용된 투명도·색상·가시성·크기·좌표를 확인합니다. `display: none`처럼 좌표가 없는 경우도 별도로 처리합니다.
- **오탐 억제:** 접근성용 숨김 문구, 메뉴·탭의 비활성 콘텐츠, 도박 예방 공지 등 정상 사례를 대조합니다. 스타일 이상만으로 위반 결과를 내지 않습니다.
- **위치:** 광고가 있는 구체적인 요소를 가리키고 선택자가 프레임 안에서 정확히 1개 요소를 찾는지 확인합니다. 부모 전체 텍스트로 중복 검출하지 않도록 합니다.
- **내보내기:** 기법별 분리, 중복 제거, 고유 ID와 스키마 검증을 거친 뒤 UTF-8(BOM 없음)으로 저장합니다. 창 닫기·중단·재실행 시 이전 결과와 혼동하지 않도록 상태를 표시합니다.

## 구현 순서

- [ ] 로컬 테스트 사이트: 4종 단독·중첩 사례, 하위 게시글·댓글, iframe, 정상 대조군
- [ ] 브라우저 탐색과 원문·스타일·선택자 수집
- [ ] 필수 탐지 4종, 광고 문구 판단, 정상 사례 오탐 보정
- [ ] `result.json` 생성, 0건·중복·스키마 검증
- [ ] URL 입력·진행 상태·결과 조회 화면
- [ ] Windows 11 실행 파일, 브라우저 리소스 포함, 경로·권한 점검
- [ ] 실행·빌드 매뉴얼과 사용설명서, 제출 자료 확인
- [ ] 여력이 있으면 결과 필터·검토 상태·추가 유형 및 `result_extra.json`

## 완료 판단

| 검증 | 확인할 결과 |
| --- | --- |
| 필수 유형 | 위장·은닉 광고 4종을 각각 검출하고 코드를 정확히 구분 |
| 중첩 기법 | 같은 요소에 두 기법이면 2건, 같은 기법이면 1건 |
| 위치 | 클래스 중복·클래스 없음·중첩 iframe에서도 요소 1개를 특정 |
| 페이지 탐색 | 쿼리가 다른 글과 댓글을 탐색하고 iframe 경로를 보존 |
| 정상 대조군 | 숨김 접근성 텍스트·예방 안내문의 오탐을 측정·개선 |
| 파일 | 검출 0건, 한글 원문, 고유 ID, BOM 없음, 필수 필드 충족 |
| 장애 | 네트워크 실패·제한시간·쓰기 권한 실패를 알리고 완료 결과와 구분 |
| 배포 | GPU·개발 환경 없는 Windows 11에서 압축 해제 후 실행 |
| 시간 | 실제 시작부터 탐색·파일 생성 완료까지 측정, 30분 이내 목표 |

정확도와 검출 개수는 자체 정답셋을 만든 뒤 측정합니다. 현재 성능 수치나 공모전 테스트 사이트 통과를 주장하지 않습니다.
