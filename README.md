## Chickadee Bot

<img width="300" height="300" alt="image" src="https://github.com/user-attachments/assets/2fe3aa9a-222b-4c1e-bb5a-b83734a70462" />

공공 웹사이트에 게시되거나 숨겨진 불법광고를 탐지하고, 유형과 위치를 확인할 수 있도록 만드는 점검 도구입니다.

행정안전부·한국지능정보사회진흥원의 **2026 공공 웹사이트 불법광고 탐지 도구 개발 공모전** 참가를 목표로 합니다.

> 현재는 기획 및 요구사항 정리 단계입니다. 이 저장소에는 문서, 결과 파일 스키마와 예시만 있으며, 탐지 프로그램·실행 파일·빌드 명령은 아직 없습니다. 아래 기능과 기술 구성은 개발 계획입니다.

## 목표

사용자가 진입 URL 하나를 입력하면 하위 페이지, 게시글, 댓글, iframe 내부를 탐색하고 불법광고 의심 요소를 찾아냅니다. 결과 화면에서 원문·탐지 기법·요소 위치를 확인하고, 평가용 `result.json`을 생성하는 흐름을 목표로 합니다.

| 필수 탐지 유형 | 코드 | 확인할 내용 |
| --- | --- | --- |
| 닮은꼴 글자 위장 | `HOMOGLYPH` | 키릴 문자, 전각 문자, 숫자 등으로 위장한 광고 문구 |
| 자모 분해 | `JAMO` | `ㅋㅏㅈㅣㄴㅗ`처럼 자모로 쪼갠 광고 문구 |
| 투명 텍스트 | `TRANSPARENT` | 배경과 같은 글자색, `opacity: 0`, `color: transparent` 등 |
| 화면 밖 은닉 | `OFFSCREEN` | 0~1px 글자, 화면 밖 배치, `display: none` 등 |

은닉 스타일 자체만으로 불법광고를 판단하지 않고, 문구와 광고 맥락을 함께 확인하는 방향으로 개발합니다. 접근성용 숨김 텍스트와 불법광고 예방 안내문 등 정상 콘텐츠의 오탐도 점검합니다.

## 개발 방향

- **실제 브라우저 기반 탐색:** 렌더링된 DOM, 적용된 CSS, iframe 내부 요소를 확인합니다.
- **규칙 기반 우선 구현:** 문자 정규화·자모 복원·광고 문구 규칙으로 기본 기능을 만들고, AI 적용은 선택사항으로 남깁니다.
- **근거 중심 결과 화면:** 페이지 URL, 유형, 원문, 요소 선택자와 진행 상태를 제공합니다.
- **Windows 11 배포:** GPU 없는 PC에서 실행할 수 있는 패키지를 목표로 합니다.

후보 구성은 Python + Playwright + PySide6, Windows 패키징은 PyInstaller입니다. 기술 스택과 버전은 구현 검증 후 확정합니다. 현재 선택한 상용 AI 서비스나 모델은 없습니다.

## 공모전 주요 조건

- 접수: **2026년 10월 23일(금) 18:00까지**, 이메일 접수
- 참가: 개인 또는 최대 5명 팀. 행정·공공기관 재직자는 소속 부서 업무와 무관한 경우에 한해 참여
- 제출: 신청 서류, Windows 11 실행 파일, 전체 소스코드, 실행·빌드 매뉴얼, 사용설명서
- 평가: GPU 없는 Windows 11 PC에서 진입 URL 하나를 입력해 실행
- 출력: 결과 화면과 별도로 UTF-8(BOM 없음)의 `result.json` 생성
- 적격평가: 정답 검출 45점 + 추출 정확도 35점 + 검출 시간 20점
- 검출 시간: 상한 30분 초과 시 **검출 시간 항목 0점**

근거 문서는 「공공 웹사이트 불법광고 탐지 도구 개발 공모전 모집요강」(2026년 9월)입니다. 요구사항 문서에 원문 페이지를 표시했으며, PDF 원문과 개인정보가 들어가는 신청 서류는 저장소에 포함하지 않았습니다. 일정과 운영 조건은 주최 측 변경 공지를 최종 확인해야 합니다.
