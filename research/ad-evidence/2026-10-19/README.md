# 광고 의심 사례 조사 자료 · 2026-10-19

공개 페이지에서 수집한 탐지 규칙 검토용 자료다. 법적 불법성 판정이나 대표성 있는 평가 데이터셋이 아니다.

- `samples.jsonl`: 직접 관찰 광고 의심 15건과 간접 문헌 사례 5건. `sample_origin`으로 구분한다.
- `negatives.jsonl`: 정상 대조군 23건.
- `sources.md`: 원본 공개 출처와 직접·간접 관찰 구분.
- `collection-report.md`: 기법별 확보 수, 증거, 제외 사유와 한계.
- `delta-report.md`: 마지막 추가 조사에서 달라진 내용.
- `validation-summary.json`: JSONL 구조·건수 점검 결과. 탐지기 성능 평가 결과가 아니다.
- `review.md`: 기존 구현에 대한 정적 검토와 사례 기반 개선 제안.

43건 중 직접 관찰 38건, 간접 문헌 5건이며 합성 사례는 없다. 직접 관찰 광고의 확인 기법은 HOMOGLYPH 4건, JAMO 1건, OFFSCREEN 3건, TRANSPARENT 0건이다. A008은 두 기법에 중복 집계된다. 네 기법별 10건 목표는 달성하지 못했다.

`dom_verified`는 이 자료에서 원본 HTML의 문자·요소·명시 스타일을 확인했다는 의미이며, 렌더링된 계산 스타일을 측정했다는 뜻이 아니다. `computed_style`, `bounding_box`, `viewport`는 측정하지 않아 null이다. `visible_only` 자료는 확보한 공개 텍스트까지만 확인했다. 각 레코드의 `limitations`를 함께 읽어야 한다.

증거 문자열은 정규화하지 않았다. 연락처·광고 목적지 등 생략 부분은 `redactions`에 기록했다. DOM 발췌는 비실행 JSON 문자열로만 취급하고 HTML로 렌더링하지 않는다. 출처 URL은 증거 위치이며 광고 목적지는 따라가지 않았다. 같은 `source_group`은 독립 사례로 무작정 중복 집계하지 않는다.

수집 자료만으로 정확도·재현율을 주장하지 않는다. 저장소 코드와 테스트를 실행하지 않았고, 이 폴더에는 탐지기 코드 변경이 없다. 공모전 제출용 `result.json`과 별개의 조사 형식이다.
