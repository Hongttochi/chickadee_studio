## 이번에 확보한 핵심 근거

- **A009, Georgia Tech 한인학생회 댓글:** `ㅂr카라`, `ㅋr지노`를 확인했다. 자체 회칙에서 학생단체 성격을 확인했으며 대학 공식 게시판·대학의 광고 추천으로 표현하지 않는다. 교육 학생단체 경계 표본으로 source_category와 scope_edge를 명시했다.
- **A010/A011, 코딩학원 게시판·식품 쇼핑몰:** 광고 도메인 끝의 `CΟΜ`은 Latin C(U+0043), Greek Ο(U+039F), Greek Μ(U+039C)다. A010은 UTF-8 바이트와 메타데이터 이스케이프도 대조했다. 불필요한 전체 광고 도메인은 보관하지 않았다. 서로 다른 캠페인 그룹으로 기록했다.
- **A012, 인도네시아 대학 학과 페이지:** 학과 설명이 있는 footer-widget 안에 실제 `<div style="display:none">`와 슬롯 광고 a/li 요소를 확인했다. 메타 설명에도 복제가 있지만 실제 비이스케이프 본문 요소를 따로 확인했다.
- **A013, 인도네시아 교육 학술지:** 푸터의 display:none 도박 링크와 `position:absolute; left:-9999px; top:-9999px; width:1px; height:1px; overflow:hidden` 래퍼를 확인했다. 1px는 박스 크기이며 글자 크기로 바꾸어 표현하지 않는다. 반복 링크는 하나의 삽입군으로 묶었다.
- **A015, 방글라데시 컴퓨터 쇼핑몰:** 라우터 상품 페이지의 실제 a 태그에 display:none과 `SLOT GACOR PIN4D`가 함께 있었다. 스크립트가 닫힌 뒤의 실제 요소임을 확인했다. 많은 반복 링크를 1건으로만 기록했다.
- **A014, 인도네시아 학술지의 중요한 함정:** 초록의 광고 코드가 `&lt;a ...&gt;`로 이스케이프된 텍스트였다. color:transparent·음수 좌표·1px 문자열이 있어도 실제 스타일로 적용된 것이 아니므로 techniques는 빈 배열이다. 광고 의심 문구와 은닉 기법 판정은 분리했다.
- **N022/N023:** 바카라 크리스털 제품명, 언론의 사칭 도박 광고 비판·인용을 정상 대조군으로 추가했다. N023의 300% 보너스·즉시 입금은 기사의 인용이며 기사 자체의 가입 권유가 아니다. 뉴스 페이지 외부 광고 iframe은 평가하지 않았다.

국내 공공·교육기관을 우선했지만 현재 직접 기법 표본은 쇼핑몰, 교육 학생단체, 사설 학원과 해외 교육기관에 편중된다. 국내 지자체 게시판에서 목표 기법을 직접 검증한 신규 사례는 없다. 해외 자료를 국내 게시판 실적처럼 표시하지 않는다. 민간 뉴스의 직접 목표 기법 광고는 확보하지 못했다.

## 데이터 해석·보안·한계

- dom_verified는 정적 HTML 문자·태그·선언을 읽어 확인한 수준이다. computed_style/bounding_box/viewport는 모두 null이다. 실제 렌더링과 CSS 우선순위·외부 스타일 최종 효과는 모른다.
- 선택자 후보는 가능한 범위에서 제공했다. 고유 시작 태그 횟수를 센 경우 그 방법을 적었지만 브라우저 querySelectorAll과 같지 않다. 고유 요소를 지정할 수 없으면 null이며, 일부 후보 선택자는 유일성 미확인으로 표시했다. 잘못 중첩된 HTML의 브라우저 교정도 미검증이다.
- frame_chain의 빈 배열은 이번 증거가 최상위 응답에서 관찰됐다는 뜻이며 페이지 전체 iframe을 조사했다는 뜻이 아니다. 간접 자료는 null이다.
- Unicode·자모·그리스/키릴 문자·공백을 원문 필드에서 임의 정규화하지 않았다. 공개 텍스트만 확인한 10개 정상 자료는 원본 바이트 동일성 보장이 없다. 변경·마스킹은 redactions에 적었다.
- 일반 이용자 개인정보, 광고 연락처, 불필요한 광고 목적지를 제외했다. 원본 페이지 전체·JavaScript·외부 이미지/영상·첨부파일은 내보내지 않는다. 최소 DOM 발췌는 JSON 문자열로만 보관하며 실행·렌더링하지 않았다.
- iframe 내부 광고, 실제 키워드가 여러 태그에 분할된 광고, 직접 TRANSPARENT 사례, 전각 문자 광고는 아직 미확보다. 합성으로 수량을 채우지 않았다.

## Chickadee Bot 개선 제안

1. **문자 변형을 근거 위치와 함께 기록(A008–A011, R005; 정상 N009/N017).** 원문과 NFC/NFKC·자모 조합·confusable 변환 결과를 별도 필드로 둔다. `ㅍ ㅏ`처럼 공백 있는 부분 분해와 `ㅋr`처럼 한글/라틴 혼합은 서로 다른 단계로 시험한다. Greek Ο/Μ와 Cyrillic сом을 코드 포인트로 구분하고 광고 문맥 없이 문자 종류만으로 경고하지 않는다.
2. **실제 DOM·선언과 문자열을 분리(A014).** HTML entity로 이스케이프된 코드, 메타데이터, 코드 인용을 스타일 규칙으로 해석하지 않는다. A014는 광고 텍스트 탐지의 양성이면서 TRANSPARENT/OFFSCREEN 기법 판정의 음성 회귀 표본이다.
3. **요소/조상별 은닉 근거(A012,A013,A015; 정상 N002/N007).** 링크 자체 display:none, 조상 display:none, 음수 좌표와 1px 박스를 각각 기록한다. 페이지 전역 숨김 CSS나 태그 크기만으로 해당 광고에 전파하지 않는다. A009의 댓글 편집용 숨김 textarea 복사본도 실제 광고 은닉과 구별한다.
4. **CSS 순서·겹침을 보존(R006/R007).** opacity0.003과0을 구별하고 색상 투명도·부모 opacity·0px/overflow 조합은 별도 근거로 남긴다. 뒤에 재선언된 동일 선택자, important, 상속·가림은 계산 스타일을 확인할 수 있는 승인 환경에서 후속 검증한다. background-color:transparent는 글자 투명과 다르며 gradient text도 자동 은닉 판정하지 않는다.
5. **정상 문맥 대조군 유지(N016,N022,N023 및 기존 N001–N021).** 브랜드·소설·학과·연구 제목, 예방·신고·기사 인용과 가입·입금·보너스 권유를 구분한다. ‘안전/보안/피해’ 단어를 무조건 정상 예외로 삼지 않는다.
6. **평가 누출 방지.** source_group·호스트·템플릿 기준으로 분리하고 같은 footer의 수십 링크를 수십 독립 사례로 세지 않는다. 교육 학생단체·해외 기관·쇼핑몰을 국내 공공기관과 별도 층으로 보고한다. 미측정 null을 정상 음성 값으로 바꾸지 않는다.
7. **증거 수준을 제품 결과에 표시.** 정적 선언, 실제 계산 CSS, 시각 확인, 간접 보고를 구분한다. 검색 요약만으로 경고를 확정하지 않고 수집 시각·원문 접근 결과·고유 선택자 검증 여부를 기록한다.

다음 조사에서는 보호 설정을 유지한 허용 브라우저가 정상 작동할 때 기존 A012/A013/A015와 정상 N002/N007의 계산 스타일을 먼저 재검증하는 것이 효율적이다. 국내 공공기관의 직접 자모/투명색 사례, 실제 태그 분할·iframe 내부 사례는 별도 부족 과제로 남긴다. 이번 자료만으로 탐지 정확도·재현율·사이트별 발생률을 주장할 수 없다. fixtures는 만들지 않았다.
