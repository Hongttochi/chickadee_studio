## 증거와 한계
수집은 순차적인 공개 텍스트/정적 HTTP 읽기였으며 광고 목적지·외부 이미지·성인 영상·첨부파일을 따라가지 않았다. 원본 JavaScript 실행, 로그인, 게시, 문의, 계정 변경, 보안 설정 변경 없이 조사했다. 실제 VM 격리 수준과 침해 가능성을 검증하지 못했으므로 안전을 보장하지 않는다.

visible_only는 원본 URL의 공개 추출 텍스트를 읽은 수준이며 스크린샷의 실제 가시성을 확인했다는 뜻이 아니다. dom_verified도 정적 응답만 확인한 경우가 있으며 라이브 DOM/계산 스타일을 뜻하지 않는다. 웹 도구는 캐시를 사용할 수 있다. collected_at은 확인 시각이며 게시 시각·실시간 존속 보장이 아니다.

선택자는 정확하게 특정할 수 없는 신규 사례에서 null이다. 계산 CSS, bounding_box, viewport는 미검증 null을 유지한다. 기존 선택자의 정적 유일성 확인과 브라우저 querySelectorAll 확인은 구별한다. frame_chain null 또는 빈 배열은 전체 iframe 검사가 끝났다는 뜻이 아니다. iframe 내부·여러 태그로 분할된 실제 광고·직접 투명색 사례는 미확보다.

원문 Unicode를 임의로 정규화하지 않았다. 발췌·연락처/목적지 마스킹은 redactions에 설명했다. 본문 전체, 일반 이용자 개인정보, 실행형 HTML/JS는 산출물에 없다. DOM 발췌는 JSON 문자열이며 렌더링하지 말아야 한다. 광고 적합성 라벨은 법적 불법성·기관 관여·침해 확정 판정이 아니다.

## Chickadee Bot 개선안
1. 원문/정규화 별도 저장 및 코드 포인트 근거(A008–A011,A016,A023,A028,A042,A043). NFC/NFKC·자모 조합·confusable/영폭/soft-hyphen 처리를 단계별 검증한다. A022/A025는 정상 파일명/문체 변형 가능성을 반영한 하드 케이스로 둔다.
2. 실제 요소·조상 선언을 추적(A012,A013,A015,A020,A031). display:none, 위치, 글자크기, 박스크기를 구분하고 계산 CSS 미확인은 unknown으로 유지한다. 접근성/메뉴 N002/N007을 대조한다.
3. HTML 코드 인용과 실제 스타일을 분리(A014). 엔티티 텍스트/메타데이터를 스타일로 실행하거나 해석하지 않는다.
4. 보너스·입금·가입·외부 유도와 문서 맥락을 조합(A034,A035,A045,A051; N021–N023). 안전/보안/피해예방 문구만으로 정상 화이트리스트를 만들지 않는다.
5. 댓글 단위 및 source_group/템플릿 단위 분리(A039/A040,A017/A051). 같은 광고가 train/test 양쪽에 들어가지 않게 그룹 분할한다.
6. 향후 허용된 실제 브라우저에서 CSS cascade·부모 opacity·배경색·iframe·태그 분할을 재검증한다. 현재 미측정값을 정상으로 대체하지 않는다.
7. 결과에 evidence level 및 수집시각을 노출하고 원문 접근 실패를 not_found나 normal로 변환하지 않는다.

이 자료로 실제 정확도·재현율·발생률을 주장할 수 없다. 재현 fixtures는 만들지 않았다.
