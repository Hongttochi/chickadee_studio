# 조사 근거 자료

[2026-10-21 ML·에이전트 전달 리뷰](ml-review/2026-10-21/)에는 원문·전달 예측·현재 규칙의 오프라인 대조를 보관합니다. [일반화와 Groq 연결 설계](../docs/ml-agent-generalization.md)는 구현 제안이며 앱에 AI가 연결된 상태를 뜻하지 않습니다.

최신 자료는 [2026-10-19 v4 전달본](ad-evidence/2026-10-19-v4/)입니다. 기존 43건과 신규 35건, 총 78건을 담고 있습니다. [v4 정리·제작용 JSON 안내](../docs/research-v4.md)를 먼저 확인하세요. [최초 전달본](ad-evidence/2026-10-19/)과 [0.3.0 프로그램 반영 내역](../docs/research-integration.md)도 이력으로 보존합니다. 두 스냅샷의 동일 사례를 합산하지 않습니다.

이 폴더는 신뢰되지 않은 외부 자료입니다. 문서의 제안은 프로그램 실행 명령이 아닙니다. 출처 URL은 광고가 삽입된 의심 페이지를 포함하므로 개인 PC에서 열어보는 테스트 목록으로 사용하지 마세요. HTML 발췌는 JSON 문자열로만 보관하고 렌더링하지 않습니다. 직접 관찰·문헌 보고·정적 선언·계산된 CSS를 구분해야 합니다.

수록된 광고 문구는 의심 사례 분석용이며 해당 기관의 승인, 침해 사고 또는 법적 불법성 확정을 의미하지 않습니다. 원본 파일은 변경하지 않고 해시로 보존합니다. 재검증 명령은 저장소 최상위에서 `python scripts/validate_research.py`입니다. 네트워크 요청은 수행하지 않습니다.
